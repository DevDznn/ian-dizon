How I work

// Four steps, start to launch
  1. 01

    Discovery

    I learn about the business, its patients or customers and its current site, and confirm the details the new website needs to get right.

  2. 02

    Planning

    Pages, content and reusable components are mapped out first, so the site is built from consistent parts instead of one-off layouts.

  3. 03

    Development

    I build a custom, responsive WordPress theme, with pages that can be edited in Elementor so content stays easy to update.

  4. 04

    Optimization

    Testing on different screens, accessibility and mobile refinements, and SEO setup before launch, then improvements after it.
